# 《琅琊榜》第一集 · 短剧版剧本《风起金陵》

- 画幅：9:16 竖屏 ｜ 时长：约 2 分 30 秒 ｜ 镜头数：40
- 改编原则：忠于原剧主线（梅岭冤案背景 → 琅琊阁预言 → 梅长苏进京 → 侯府安顿 →
  皇帝设擂为霓凰择婿 → 双王觊觎），按短剧节奏压缩为 6 场，每 20-30 秒一个钩子。
- 一句话故事：一个「已经死了」的人，带着七万冤魂的名字回京城复仇——而全天下
  都在抢着得到他。

## S0 冷开场：七万人的雪（0:00-0:18，5 镜）

意象化处理：水墨质感，不出现清晰人脸（省一致性成本且风格化）。

旁白（低沉男声）：十二年前，梅岭一战，赤焰军七万将士——含冤，埋骨。

画面：墨色天空大雪覆山脊，残破赤色军旗半埋雪中；旗缘焦黑火星明灭；
无数长枪斜插雪原如林，枪上系白绫；少年剪影立于崖边火光与雪之间，背对镜头；
火光被大雪吞没，画面转墨黑。字卡：**十二年后**。

## S1 琅琊阁：同一句预言（0:18-0:50，7 镜）

云海之上琅琊阁飞檐孤悬。太子亲信玄衣队上山求问储位；阁主不露脸，只有
执笔的手与纸卷。卷上墨字：「麒麟才子，得之可得天下。」下山时誉王红衣队
与玄衣队在山道相遇，勒马对视。纸卷从阁楼飘落云海（慢镜）。

旁白：同一个答案，送进了两个王府。太子攥紧纸卷，指节发白；誉王同样。

## S2 廊州码头：江左盟立威（0:50-1:35，10 镜，动作高光）

晨雾江面乌篷船队。双刹帮季赢带人拦船挑衅：「双刹帮的水，也敢闯？」
船舱布帘微动，苍白修长的手按住书卷（不露脸预告）；黑衣少年飞流睁眼瞳孔一凛；
飞流自桅杆跃下，一脚踹飞季赢的刀，稳落船头（慢镜+快剪，本集第一动作高光）；
黎纲率江左盟灰衣劲装列阵船舷；季赢跪服：「江、江左盟……季赢有眼无珠！」

白衣梅长苏缓步出舱（**首次正脸=全剧定妆镜头**）：素白广袖、银灰披风、
苍白脸色，拢袖立于船头。台词（清淡）：「起来。江面风大，别跪坏了膝盖。」

码头上萧景睿惊喜抱拳：「苏兄！」言豫津压低声音摇扇：「这位就是……麒麟才子？」
船队起航。旁白：琅琊榜首，江左梅郎——进京了。

## S3 进京：化名苏哲（1:35-2:05，6 镜）

金陵城墙巍峨、朱门酒旗、人流如织（缓推航拍感）。船舱夜话：言豫津
「先生既入金陵，总得有个名目。」梅长苏卷帘望岸上灯火：「就叫——苏哲。」
城门外大渝使节车队（异域旗号）与梅长苏马车交错而过；车内侧脸眸光微沉，帘落。
宁国侯府门前萧景睿、谢弼迎「苏先生」入门。侯府庭院夜，灯笼次第亮起，
修竹影里梅长苏背影轻咳，飞流递上手炉。

## S4 皇宫：擂台择婿（2:05-2:40，8 镜）

大殿蟠龙金柱烛影。梁帝明黄龙袍侧坐凤座（首次出场用 3/4 侧脸，降低一致性负担），
手指缓缓敲击扶手（多疑习惯动作）。高湛躬身报：「云南王府的折子，又到了。」
梁帝冷笑：「十万铁骑……她的翅膀，硬了。」圣旨特写+宣旨画外音：「迎凤楼设擂，
为穆霓凰郡主——择婿！」

【改编标注】霓凰英姿前置：银甲红缨近景按剑立于演武场，目光如霜（原剧 EP1
霓凰戏份在后，此处前置一个形象镜头作视觉钩子；如评委较真可在 demo 讲解时说明）。

迎凤楼擂台搭起，京城公子骚动。誉王与太子各自与幕僚密议（过肩/背影处理）。
梁帝独坐烛影低语：「麒麟才子……得之可得天下？朕，倒要看看。」

## S5 收尾：双钩（2:40-2:55，4 镜）

侯府高台夜。梅长苏拢袖远望宫城灯火，轻咳，目光却亮。面部特写：苍白的脸，
眼底映着宫灯的火光。1 秒梅岭雪 flash。

旁白：他回来了。带着——七万人的名字。

## 改编幅度说明（诚实标注）

1. 霓凰英姿镜头前置（原剧 EP1 无正面戏）——视觉钩子需要女性高光镜头。
2. 双刹帮冲突压缩为一场立威戏，删去卓/谢两家支线与谢玉暗线（留到第二集钩子）。
3. 言豫津随行进京的时点略作合并；「苏哲」化名对白场景合并进船舱夜话。
4. 梁帝「朕倒要看看」台词为短剧化原创内心外化，人物动机忠于原剧多疑设定。
