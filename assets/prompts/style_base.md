# 全局风格基石（Style Base）

## 画面风格（拼在每条提示词开头）

```
中国古装正剧质感，电影级画面，低饱和青灰色调配暖烛金点缀，自然光效，
织物与甲胄材质细节，9:16 竖构图人物中置，上三分之一留天光、下三分之一留字幕位
```

- 正片（S1-S5）：实感电影风。S0 冷开场：额外加「水墨绘画质感」并把 scene 锚换成水墨描述。
- 所有字卡文字（预言、圣旨、片名）一律**后期字幕/贴图**完成，不靠生成——规避 AI 乱码字。

## 全局负面词（拼在每条提示词尾部）

```
负面：现代元素、错朝代服饰、塑料质感、过曝、多余手指、肢体畸变、人脸畸变、
背景文字乱码、水印、logo、多余人物
```

## 一致性铁律（来源：纳逗教程 + drama-skills 资产层思想）

1. **角色锚点串全量复用**：镜头提示词 = 风格基石 + 场景锚(scene_prompt) + 角色锚
   (appearance_prompt) + 本镜动作/光线。只改最后一段，前三段一字不动。
2. **先图后视频**：每镜先出关键帧图，对照角色参考图四查（脸/发型/服装/光线），
   通过后再图生视频。
3. **相邻镜互为参考帧**：同场相邻镜头生成时带上前一镜的关键帧做参考图。
4. **每次只改一个变量**：重 roll 时只改一个描述词，便于归因。
5. **单镜只做一件事**：一个动作、一个情绪；动作复杂就拆成两镜。
6. **服装状态变化必须另出设定图**：模型理解不了「衣服逐渐破」，就为每种状态单独立卡。
7. **光线时段锁定在场景卡**：镜头提示词不再自行描述时段，避免同场镜头冷暖打架。

## 提示词模板（tools/build_prompts.py 自动拼装）

```
[风格基石] + [场景锚] + [角色锚 × 出场角色] + [本镜: 景别/运镜/动作/光线补充] + [负面词]
```
