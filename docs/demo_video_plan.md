# Demo 视频方案（比赛交付物）

要求回顾：demo 视频随源码上传 GitHub，是评委理解作品的第一入口。
目标 60-90 秒，结构「成果先行 → 过程证据 → 回到成果」。

## 录制要点

- 用 QuickTime/obs 录屏 + 手机放成片画中画；节奏卡 BGM。
- 第 3 段务必出现「重 roll 后成功」的真实过程——评委要看真实工作方式，不是广告片。
- 结尾贴 GitHub 仓库地址与架构文档截图。
- 文件名 `demo.mp4` 放仓库根目录，README 顶部挂预览 GIF（取 S2-08 定妆帧）。

## 演讲口径（若入围路演）

1. 为什么是这个题：视觉产出型选题，AI 视频生成的最佳展示场。
2. 方法论一句话：创作决策全部数据化，生成只是执行——所以可复跑、可交接、可复制到任意 IP。
3. 商业叙事：这不是做了一集，而是验证了一条「IP → 短剧」的半自动产线
   （换个 JSON 就能做第二集/别的剧）。
4. 诚实说明 4 项改编与 2 项平台降级（评委好感度 > 完美人设）。
