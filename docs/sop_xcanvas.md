# XCanvas（灯虹）操作 SOP 与 48 小时作战计划

平台入口：https://aicanvas.qnlinking.com （灯虹·一站式 AI 影像创作平台）
本 SOP 假设平台具备：剧本/文本节点、图片生成（文生图/融图/多参考）、图生视频、
TTS、剪辑导出。**登录后请先对照本清单核实功能入口名称**，有出入直接在本文档上改
（文档修改本身也是比赛的过程痕迹）。

## 第 0 步：建项目（15 分钟）

1. 新建项目「琅琊榜EP1·风起金陵」，画幅选 9:16（若平台视频生成 16:9 质量明显更好，
   降级方案：全片改 16:9 横屏，分镜表 aspect 字段同步改，构图描述不变）。
2. 跑一遍 `python3 tools/build_prompts.py`，把 `build/prompts/` 里的提示词当作
   平台输入的唯一事实来源。

## 第 1 步：角色定妆（1.5 小时，一致性成败在此）

1. 逐个角色：用角色卡 `appearance_prompt` 生成 **4 张候选**定妆图。
2. 选 1 张锁定为「角色参考图」，再用多角度/融图产出正面+侧面+全身三视图。
3. 服装状态变化的角色（本集无，续集注意）须为每种状态单独出图。
4. 参考图命名 `<角色id>_ref.png`，回传到仓库 `build/refs/`（git 留痕）。
5. 省成本角色不折腾：琅琊阁主（只手）、太子/誉王（背影侧脸）、高湛（背影画外音）。

## 第 2 步：先跑通 30 秒（1 小时，铁律）

用 S0 全部 5 镜 + S1-01/02 跑通「图 → 视频 → TTS → 粗剪」全链路，导出一段
30 秒样片。链路不通就换路（例如视频生成不可用则全部走「关键帧+运镜动画」），
**链路通了才开始铺量**。

## 第 3 步：铺关键帧（3 小时）

1. 按场景分组生成全部 37 个生成类镜头的关键帧图（post_only 的 3 镜跳过）。
2. 每张出来立即四查：脸/发型/服装/光线，对照角色参考图。
3. 不合格只重出该镜：同提示词重 roll ≤3 次 → 改一个变量（动作或景别）再 roll
   → 仍失败执行该镜 `fallback` 字段的降级方案。
4. 同场相邻镜头把前一镜关键帧挂作参考图。

## 第 4 步：图生视频 + TTS（4 小时）

1. 视频逐镜生成，单镜动作宁少勿杂。
2. TTS 按角色卡 `tts` 字段选音色语速；旁白单独一轨全部先出。
3. 台词字幕从分镜表 `dialogue` 导出，后期统一贴（不靠画面生成文字）。

## 第 5 步：合成（2 小时）

1. 粗剪：按 S0→S5 场序铺结构，先不加音效。
2. 精剪：对齐钩子节奏（钩子时间表见 `ep1_script.md`）。
3. 声音：配音 → 音效 → BGM（BGM 设计见 `style_base.md`）。
4. 字幕字卡：台词、预言/圣旨贴字、片名字卡、二创声明。
5. 双向检查：关声音看画面是否讲得清；关画面听声音是否成立。
6. 导出 1080×1920，检查黑帧/静音/音画漂移。

## 第 6 步：交付（周一 8:00 前完成，留 1 小时缓冲）

- demo 视频按 `demo_video_plan.md` 录制。
- `architecture.md` 补分工与实拍截图，README 截成片二维码/预览 GIF。
- 最后 PR + tag，确认 10/26 09:00 前仓库无新提交。

## 失败对策速查（综合纳逗教程与实测共识）

| 症状 | 处理 |
|---|---|
| 角色变脸 | 回融图/多参考；删除互相打架的动作词 |
| 镜头跳戏 | 统一场景光线锚；相邻镜互参考；事后统一调色 |
| 生成随机不可控 | 只用图生视频；文生仅做探索 |
| 动作镜头崩坏 | 拆两镜；或三连静帧+震屏；最差 Ken Burns |
| 视频带乱码字 | 一律后期贴字 |
| 平台某功能缺失 | 记录到本文档，用降级方案，demo 讲解时说明取舍 |

## 模型备注

比赛内网关已可用的 `minimax/minimax-h3-max`（七牛 provider）可作为剧本层/提示词层
的迭代后端；开源产线 drama-skills 的 produce 层也支持 MiniMax H3 适配器，若时间
富余可把本仓库接入全自动生成（详见 `workflows_reference.md`）。
